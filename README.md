# TCP Client-Server System

Network Programming Assignment for IE2102.

## Overview

This project implements a TCP client-server architecture using C and Python.

### Features

- TCP socket communication
- User registration
- User authentication
- Password hashing using SHA-256
- Session token generation
- Multiprocessing using fork()
- Logging system
- Request rate limiting
- User data storage

## Technologies

- C
- Python
- Linux
- TCP/IP Socket Programming
- OpenSSL

## Project Structure

- server_2685.c : TCP Server
- client_2685.py : Python Client
- Makefile_2685 : Build Script
- server_IT24102685.log : Server Logs
- report/ : Assignment Report
